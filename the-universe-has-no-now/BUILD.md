# BUILD — how this film is reproduced from source

Everything in `film.mp4` (picture, voice, music, sound design, captions) is generated by code in this
directory. No stock footage, no downloaded images, no generative video or image models were used.

## Environment
- Linux, Python 3.13, ffmpeg 6.1 (libx264, aac, loudnorm/ebur128), 4 CPU cores, no GPU.
- Python packages: `numpy scipy skia-python soundfile pillow kokoro-onnx onnxruntime pytest`
  (`pip install -r source/requirements.txt`).
- Fonts: Inter / Inter Display (OpenType, system), DejaVu (mono/serif for readouts and equations).
- `skia-python` needs `libEGL.so.1`; in a headless container without it, symlink the copies that ship with
  Playwright's Chromium: `ln -s /opt/pw-browsers/chromium-*/chrome-linux/libEGL.so /root/lib/libEGL.so.1`
  (same for `libGLESv2.so.2`) and export `LD_LIBRARY_PATH=/root/lib` (the Makefile does this).
- Kokoro voice model (≈330 MB, Apache-2.0): `kokoro-v1.0.onnx` and `voices-v1.0.bin` from
  https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.0 → `build/models/`.

## Pipeline (`make all`)
1. `source/script/script.py` — the shot list and every narration sentence (single source of truth).
2. `make narration` → `source/audio/tts.py`: one WAV per sentence (Kokoro, voice `af_heart`, speed 0.9),
   post-processed (48 kHz, trim, HPF, presence, compression) into `voice/lines/` + `voice/lines.json`.
3. `make timeline` → `source/render/nonow/timeline.py`: picture durations follow the measured narration
   (`lead` + lines + pauses + `tail`, never shorter than `min_dur`); dissolves overlap, dips fade through
   black. Output `build/timeline.json` drives picture, music, sound design and captions.
4. `make audio` → `music.py` (procedural score per act), `sfx_track.py` (cue sheet from the shots' `sfx`
   dicts), `mix.py` (voice-ducked mix, EBU R128 two-pass `loudnorm` to −14 LUFS / −1.5 dBTP).
5. `make captions` → `captions.srt` / `captions.vtt` from the sentence timings.
6. `make film` → `nonow.render film`: 4 worker processes render contiguous frame ranges straight into
   ffmpeg (rawvideo → libx264 CRF 18), concatenated losslessly; `source/mux.py` adds the mix and keeps the
   repository copy under 100 MB (two-pass re-encode only if needed; the CRF-18 master stays in `build/`).
7. `make trailer` → `trailer/trailer_script.py` + `trailer/build_trailer.py` (own narration and cue).
8. `make shorts` → `source/shorts.py`: three 9:16 cuts from the master with burned-in captions.
9. `make thumbnail` → `source/thumbnail.py` (ray-traced black hole + typography).
10. `make docs` → `STORYBOARD.md` regenerated from the script and timeline.
11. `make test` → physics, pipeline and technical QC tests in `tests/`.

Render time on 4 cores: preview (¼ res, 6 fps) ≈ 10 min; full 1080p24 ≈ 80 min.

## Where things are
```
source/script/script.py          shot list + narration (edit here, then `make all`)
source/render/nonow/core.py      frame buffer, Skia layers, bloom/grain/vignette, star catalogue, silhouettes
source/render/nonow/text.py      typographic system (sizes, tracking, roles)
source/render/nonow/bh.py        Schwarzschild ray tracer (geodesic table, disk, redshift, sky)
source/render/nonow/scenes/*.py  one module per scene type; `render(ctx, t, dur, params, shot)`
source/render/nonow/timeline.py  timing model; frame → (shot, local time, blend weight)
source/render/nonow/render.py    CLI: still / shot / frames / film
source/audio/synth.py            oscillators, envelopes, filters, reverb, panning
source/audio/music.py            the score (act by act)
source/audio/sfx.py              sound-design library (ticks, pulses, UI, whooshes, drones)
source/audio/mix.py              mix + loudness normalisation
build/                           intermediates (ignored by git): models, timeline.json, segments, previews
voice/, music/, sound-design/    stems (`voice/lines/*.wav` are regenerated; ignored by git)
```

## Changing the film
- Edit a sentence → `make narration timeline audio captions` and re-render only the affected shots:
  `cd source/render && python -m nonow.render shot --id S31 --out ../../build/S31.mp4`.
- Preview a frame: `python -m nonow.render still --id S35 --lt 6 --out x.png --scale 0.5`.
- Black-hole camera paths live in `scenes/blackhole.py::cam_path`; disk physics in `bh.py::render_bh`.
